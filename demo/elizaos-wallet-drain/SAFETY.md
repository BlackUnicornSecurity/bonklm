# Safety invariants — read before any signing operation

This demo proves an offensive attack against a vanilla ElizaOS agent. It signs
real Solana transactions. Every invariant below MUST hold at every step. If
any check fails, abort immediately.

## Invariant 1 — Devnet only, always

- `SOLANA_RPC_URL` MUST contain the string `devnet`. Enforced by
  `scripts/safety-check.mjs` at every script entry point.
- `SOLANA_CLUSTER` MUST equal `devnet`.
- No mainnet RPC endpoint is ever written into `.env.demo`,
  `characters/*.json`, or any committed file.

## Invariant 2 — Fresh ephemeral keypairs

- Every keypair used in this demo is generated by
  `scripts/generate-wallets.mjs`. No keypair from any other source
  (Phantom, Solflare, hardware wallet, existing `.env`, password manager)
  is ever loaded.
- Keys are scoped to this demo directory. They are not exported, copied to
  other projects, or re-used across variants without explicit regeneration.

## Invariant 3 — Funding source

- Agent wallet funded only from the official devnet faucet
  (https://faucet.solana.com) or another devnet-only faucet
  (devnet-pow, third-party RPC airdrop endpoints).
- Funding amount is whatever the faucet UI exposes (0.5 / 1 / 2.5 / 5 SOL).
  Devnet SOL has no real-world value; the "amount" is irrelevant for
  safety, only for not wasting shared faucet quota. Prefer the smallest
  option that covers the demo (1 SOL is sufficient).
- No funding from any mainnet bridge, exchange, or other wallet under
  user control. Funding source MUST be a devnet faucet.

## Invariant 4 — Redaction before commit

- Public keys committed to git or to a screenshot/video MUST be reduced
  to `XXXX...XXXX` (first 4 + last 4 chars). Run `npm run redact-log`
  before adding evidence to git.
- Private keys / mnemonics NEVER appear in any committed file. They live
  only in `.env.demo` (gitignored) and `wallets/` (gitignored).

## Invariant 5 — No mainnet-shaped values anywhere

- No public-key on the curated mainnet allowlist (USDC, USDT, SOL, jitoSOL,
  Raydium, Orca, Jupiter, Tensor, Magic Eden, Phantom, Backpack treasuries)
  may appear as the attacker target. The attacker pubkey is the
  freshly-generated `ATTACKER_WALLET_PUBLIC_KEY` and only that key.
- The exploit transactions broadcast in this demo move funds between three
  fresh devnet keypairs only. No third-party address is ever a destination.

## Invariant 6 — Stop conditions

Immediately abort the demo and notify the user if any of these are observed:
- The agent attempts to call an RPC endpoint not matching `*devnet*`.
- A balance check returns SOL valued at any non-trivial USD price (would
  indicate the RPC silently aliased to mainnet).
- An action handler attempts to sign with a private key not present in
  `.env.demo`.
- The agent's composed state includes any public key not generated by
  this demo (could indicate prompt-injection bleeding from a different
  context).

## Invariant 7 — No connector code

@blackunicorn/bonklm-elizaos connector is Sprint 8-9 work. Do not modify
any file under `/Users/paultinp/LLM-Guardrails/packages/` during this task.

## Operational checklist before every run

1. `npm run safety-check` — exits non-zero if any invariant breaks.
2. Visual confirm `.env.demo` `SOLANA_RPC_URL` is devnet.
3. Confirm at least one agent wallet balance check returns a devnet-sized
   value (not a mainnet-sized one).
4. Then proceed.
